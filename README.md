# Fundamentos de Machine Learning — CRISP-DM

Este repositorio contiene los proyectos prácticos y evaluaciones desarrollados para la asignatura **Fundamentos de Machine Learning**, estructurados bajo la metodología estándar de la industria **CRISP-DM** (Cross-Industry Standard Process for Data Mining).

## 🚀 Plan de Aprendizaje y Estructura del Repositorio

El contenido se divide en las fases del ciclo de vida de un proyecto de ciencia de datos:

1. **Análisis Exploratorio de Datos (EDA) y Transformación:** Limpieza, visualización, tratamiento de valores nulos, codificación de variables y normalización.
2. **Modelos de Regresión (Evaluación Actual):** Entrenamiento de múltiples algoritmos para predecir variables continuas, evaluación del error ($R^2$, MAE, MSE, RMSE) e interactividad.
3. **Modelos de Clasificación (Próximamente):** Modelado predictivo para variables categóricas, métricas de clasificación binaria (Accuracy, Precision, Recall, F1-Score) y algoritmos como KNN.
4. **Modelos Avanzados y Ensamblados (Próximamente):** Random Forest y técnicas de ensamble de modelos.
5. **Reducción de Dimensionalidad y Puesta en Producción (Próximamente):** PCA/Feature Selection y despliegue del modelo final.
